# Product

## Register

brand

## Users

Codex users, plugin authors, and developers who work across different task
types and want predictable control over which skills are available. They are
evaluating the project quickly, often from GitHub, and need to understand the
workflow before installing a macOS utility.

## Product Purpose

Explain how Skill Session Profiles manages global defaults, reusable profiles,
and persistent task configuration. Success means a visitor can understand the
product in one viewport, inspect the real interface, and reach the GitHub
repository or macOS release page without friction.

## Brand Personality

Clear, deliberate, and dependable. The voice is concise and technical without
using terminal aesthetics as decoration.

## Anti-references

- Generic AI SaaS landing pages with purple gradients or glowing blobs.
- Fake dashboards, fabricated metrics, and invented customer logos.
- Card-heavy layouts that hide the real product behind marketing copy.
- Overly editorial magazine styling that competes with the utility.

## Design Principles

1. Show the real product before explaining it.
2. Let whitespace and typography create confidence.
3. Make every claim traceable to a visible product capability.
4. Keep installation and source access obvious.
5. Preserve the application's restrained Command Blue identity.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support keyboard navigation, visible focus states,
reduced-motion preferences, high text contrast, semantic landmarks, and a
complete Chinese and English experience.
